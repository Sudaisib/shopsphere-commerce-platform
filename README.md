# ShopSphere Commerce Platform

## Overview

ShopSphere Commerce Platform is a fictional enterprise e-commerce application created as a realistic project for learning Git and GitHub.

The project contains frontend, backend, API, infrastructure, CI/CD, configuration, documentation, testing and automation files.

The purpose of this repository is to practice professional Git workflows including:

- Repository initialization
- File tracking
- Staging
- Committing
- Branching
- Merging
- Merge conflict resolution
- Restoring files
- Stashing changes
- Rebasing
- Reverting commits
- Squashing commits
- Remote repositories
- GitHub Push, Fetch and Pull
- Pull Requests and collaboration
